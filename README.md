# Vindora — Arabic dropshipping storefront demo

Open `index.html` in a browser. No build step or dependencies are required (the Cairo font uses Google Fonts when internet is available).

## Included
Responsive RTL storefront, sample product catalog, category filtering, search, sorting, persistent shopping cart, quantity controls, demo coupon `VINDORA10`, estimated shipping, demo checkout, local demo order storage, contact and newsletter demo forms, and editable policy placeholders.

## Before accepting real orders
This is a **front-end demo**, not a production e-commerce backend. Replace the sample emoji/product data in `app.js` with licensed real images, actual descriptions, supplier prices and inventory. Build and secure a server/database and an admin dashboard; implement server-side price/stock/coupon validation, authenticated order management, real payment gateway or verified cash-on-delivery workflows, shipping carrier integration, transactional email/SMS, spam protection, customer support contact information, legal terms, privacy and returns policies, HTTPS, tax handling, and compliance with applicable consumer/data-protection laws. Do not treat browser localStorage orders as real orders. Avoid storing customer personal data in localStorage in a production version.

## Files
- `index.html`: page structure
- `style.css`: responsive design
- `app.js`: demo products and interactive features
